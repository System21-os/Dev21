STRATEGIC PIVOT

Mengapa Kita Harus Pindah ke Server Profesional?

Apps Script adalah solusi uji coba (prototipe). Untuk kebutuhan korporasi skala bioskop nasional, platform server mandiri adalah keharusan mutlak.

🛑
Masa Lalu: Keterbatasan Google Apps Script
  • Kecepatan Terbatas: Menunggu 5 - 15 detik saat membuka laporan karena harus membaca Google Sheets.
  • Batasan Kuota Harian: Google membatasi waktu eksekusi maksimal 6 menit (rentan gagal saat memproses data besar).
  • Ketergantungan Eksternal: Jika koneksi Google Drive lambat atau diblokir di jaringan bioskop, aplikasi mati total.
💎
Masa Depan: Keunggulan Server Profesional Mandiri
  • Kecepatan Kilat (< 1 Detik): Data tersimpan di basis data lokal SQLite berkecepatan tinggi.
  • Tanpa Batasan Kuota: Mampu memproses ratusan ribu baris data transaksi bioskop tanpa batasan waktu.
  • 100% Kontrol Internal: Berjalan di infrastruktur server milik Cinema XXI sendiri, aman, dan bisa diakses intranet maupun publik.
💡
Analogi Sederhana untuk Manajemen:
"Apps Script itu seperti menyewa warung tenda di tanah orang lain—mudah dibuka tetapi dibatasi jam operasional dan cuaca. Sementara migrasi ke Server Profesional ini seperti membangun gedung ruko milik sendiri—bebas kita buka 24 jam, kokoh, dan siap menampung ribuan pengunjung."
PRODUCT REQUIREMENTS (PRD)

PRD: Definisi & Kebutuhan Produk

Gambaran komprehensif produk: Siapa penggunanya, apa masalah yang diselesaikan, dan apa ukuran keberhasilannya.

1. Masalah yang Diselesaikan

Manajemen kesulitan memantau capaian target penjualan makanan/minuman (F&B) dan tiket di ratusan bioskop secara real-time karena laporan Excel terpisah-pisah dan lambat diolah.

2. Target Pengguna (Persona)
  • Direksi & Head Office: Melihat performa nasional & ranking wilayah.
  • Regional Manager (RM): Memantau bioskop di wilayah provinsinya.
  • Cinema Manager (Area): Mengevaluasi capaian bulanan outletnya.
3. Tolok Ukur Keberhasilan (KPI)
  • Integritas Finansial: 100% akurasi kalkulasi SPH & GBO.
  • Waktu Akses: Dashboard terbuka di bawah 1 detik.
  • Kemandirian Sistem: 0% dependensi ke cloud luar.
4. Fitur-Fitur Kunci Produk (Core Features)
Executive Overview

Kartu metrik Omzet F&B, Penonton, SPH, dan % pencapaian target bulanan.

Peta Sebaran Nasional

Peta Indonesia (38 provinsi) interaktif tanpa butuh internet luar.

Outlet Drilldown

Analisis riwayat ketercapaian target per bioskop tiap bulannya.

Asisten Analisis AI

Chatbox cerdas untuk merangkum tren penjualan secara instan.

DAILY BUSINESS PROCESS

Alur Kerja Bisnis Sehari-hari

Bagaimana tim operasional menggunakan aplikasi ini mulai dari input data hingga terbitnya laporan eksekutif.

LANGKAH 1

Upload Data Penjualan

Admin mengunggah file Excel penjualan bioskop. Sistem otomatis menyesuaikan tanggal transaksi dengan Waktu Indonesia Barat (WIB).

→
LANGKAH 2

Penyelarasan Master Data

Sistem mencocokkan data bioskop baru ke kota, regional, dan merek layar bioskop (XXI biasa, Premiere, atau IMAX).

→
LANGKAH 3

Kalkulasi KPI Otomatis

Sistem menghitung rasio belanja penonton (SPH), selisih target, dan pertumbuhan penjualan dibandingkan bulan lalu.

→
LANGKAH 4

Penyajian Dashboard Sesuai Jabatan

Direksi melihat seluruh Indonesia, Regional Manager hanya melihat wilayahnya, dan Cinema Manager hanya melihat bioskopnya.

Rumus Finansial Bisnis: SPH (Spend Per Head)

Sistem menggunakan prinsip keuangan ketat: Jumlahkan semua omzet dulu, baru bagi dengan total penonton. Hal ini mencegah kesalahan hitung jika ada bioskop yang penontonnya sedikit tetapi belanjanya besar.

Perhitungan Pertumbuhan (Growth) yang Adil

Jika manajemen melihat performa tanggal 1 - 15 Oktober (15 hari), sistem otomatis membandingkannya dengan 15 hari persis sebelumnya (16 - 30 September).

MIGRATION ROADMAP

Workflow Migrasi: Dari Laptop Sampai Hosting Publik

Panduan langkah demi langkah yang jelas dan terstruktur untuk memindahkan aplikasi ke server manajemen.

TAHAP 1

Kemas Kode & Database

Kode di laptop sudah bersih dan lengkap. Database SQLite app.db disalin utuh berisi seluruh riwayat penjualan.

Hasil: 1 Folder Rapi & Mandiri
→
TAHAP 2

Kirim ke Server IT Internal

Folder disalin ke komputer server internal IT (Linux / Windows Server) yang sudah dipasang Node.js 22.

Lokasi: Server Kantor XXI
→
TAHAP 3

Nyalakan Sebagai Service 24/7

Dijalankan menggunakan Docker atau PM2 agar aplikasi selalu menyala otomatis meskipun server mati lampu/restart.

Status: Aktif di Background
→
TAHAP 4

Sambungkan ke Domain Publik

Tim IT memasang Nginx dan mengarahkan domain perusahaan (misal: kpi.cinema21.co.id) lengkap dengan gembok SSL (HTTPS).

Status: Live & Siap Diakses
Kemudahan Bagi Tim IT Dev (Tinggal Hosting Saja)

Semua file pendukung server seperti Dockerfile, docker-compose.yml, dan nginx-production.conf sudah dibuatkan di dalam folder proyek. Tim IT tidak perlu pusing menyusun konfigurasi dari nol—cukup jalankan satu perintah docker compose up -d dan website langsung aktif.

SECURITY & RELIABILITY

Keamanan Data & Temuan Kunci Rahasia

Menjelaskan kondisi keamanan sistem dengan transparan agar Head IT merasa tenang dan yakin.

🛡️
Apa yang Sudah Sangat Aman?
  • Password Pengguna Terkunci Rapat: Kata sandi diacak dengan rumus enkripsi tinggi (PBKDF2) dan kunci rahasia (*pepper*) yang tidak disimpan di database.
  • Pintu Masuk Terjaga (Whitelist): Pengguna dari browser hanya diizinkan memanggil fungsi laporan yang sudah disetujui, tidak bisa sembarangan mengutak-atik sistem.
  • Kebal Gangguan Internet Luar: Seluruh font, ikon, dan peta disimpan di dalam server internal sendiri (tidak takut diblokir jaringan).
🔍
Temuan Audit: 1 Kunci yang Harus Dirapikan

Dalam pemeriksaan kode, ditemukan kunci AI (Anthropic API Key) bekas uji coba lama yang masih tertulis di dalam file Code.gs baris 610.

⚠️
Solusi Cepat Sebelum Serah-Terima:
Kunci lama tersebut cukup dihapus dari kode. Kunci baru yang resmi dari kantor cukup dimasukkan ke file rahasia .env di server. Sangat mudah dan aman!
