PERTANYAAN 1 · DEPLOYMENT STRATEGY

Migrasi ke Server Internal Management

Langkah terstruktur memindahkan runtime dari laptop pengembang ke infrastruktur server IT (Linux/Windows Server).

🖥️
1. Server Prep
Instalasi Node.js 22.13+ LTS di Server Linux (Ubuntu/Debian) atau Windows Server. Buka port 3000 internal.
📂
2. Transfer & DB
Copy source code, file app.db, dan siapkan .env dengan HOST=0.0.0.0 & ALLOWED_HOSTS.
🛡️
3. Reverse Proxy
Pasang Nginx / IIS dengan sertifikat SSL/HTTPS internal. Proxy pass traffic dari port 443 ke 3000.
🔄
4. Daemon & Cron
Jalankan via PM2 atau Systemd service (Auto-restart on reboot). Pasang cron backup database berkala.
Command Eksekusi di Server Internal:
# Jalankan via PM2 Process Manager
pm2 start apps-script/server/start.js --name "kpi-analyst" --node-args="--disable-warning=ExperimentalWarning"
pm2 startup && pm2 save

PERTANYAAN 3 · SECURITY AUDIT

Kondisi Keamanan Kode & Temuan Hardcoded Key

Evaluasi keamanan secara transparan untuk meyakinkan standar InfoSec Head IT.

✓
Lapisan Keamanan yang Sudah Sangat Baik
  • Password Hashing: PBKDF2-HMAC-SHA256 dengan Salt dinamis per user + Secret Pepper terpisah di .env.
  • RPC Whitelisting: Hanya fungsi dalam set DIIZINKAN di start.js yang dapat dipanggil dari HTTP client.
  • Host & CSRF Guard: Blokir DNS Rebinding lewat pengecekan ALLOWED_HOSTS dan validasi Origin.
  • Rate Limiting: Throttle otomatis terhadap serangan brute-force login.
⚠
Temuan Celah Kritis (Vulnerability Finding)

Ditemukan Anthropic API Key yang di-hardcode di file legacy:
apps-script/Code.gs (Line 610) di dalam fungsi setApiKeyOnce().

// Temuan di Code.gs baris 610:
PropertiesService.getScriptProperties().setProperty(
'ANTHROPIC_API_KEY', 'sk-ant-api03-cJToyxE5co...'
);

Rencana Mitigasi Cepat: Revoke key di console Anthropic, hapus fungsi hardcode dari Code.gs, dan wajibkan injeksi via .env.
