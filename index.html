SECURITY AUDIT & REMEDIATION

Analisis Keamanan & Mitigasi Kunci API

Audit transparan atas postur keamanan kode sumber dan tindakan perbaikan yang telah disiapkan.

✓
Lapisan Proteksi yang Sangat Solid
  • Kriptografi Sandi: PBKDF2-HMAC-SHA256 dengan Salt acak unik per akun + Secret Pepper terisolasi di berkas .env.
  • RPC Function Whitelisting: Hanya 28 fungsi legal di dalam set DIIZINKAN yang boleh dipanggil dari browser melalui HTTP POST.
  • Anti DNS-Rebinding: Pengecekan ketat header Host terhadap daftar ALLOWED_HOSTS.
  • Anti Cross-Site Request Forgery (CSRF): Validasi Origin / Referer header pada seluruh pemanggilan endpoint API.
⚠
Temuan Kritis & Rencana Remediasi

Ditemukan kunci API Anthropic yang tercatat di dalam berkas legacy:
apps-script/Code.gs (Baris 610) fungsi setApiKeyOnce().

// Temuan di Code.gs baris 610:
PropertiesService.getScriptProperties().setProperty(
'ANTHROPIC_API_KEY', 'sk-ant-api03-cJToyx...'
);

Langkah Mitigasi: Kunci segera di-revoke di konsol AI. Kode tersebut dihapus, dan sistem dialihkan 100% membaca dari process.env.ANTHROPIC_API_KEY.

TURNKEY DEPLOYMENT

Panduan Instalasi & Hosting Publik Siap Pakai

Langkah praktis bagi Tim IT DevOps untuk men-deploy aplikasi ke server produksi publik dalam hitungan menit.

🐳
Opsi 1: Docker Container (Sangat Direkomendasikan)

File Dockerfile dan docker-compose.yml sudah tersedia di root proyek.

# 1. Masuk ke folder proyek di server publik
cd /opt/kpi-analyst

# 2. Siapkan file environment
cp .env.example .env
nano .env # Atur ALLOWED_HOSTS & AUTH_PEPPER

# 3. Jalankan container produksi
docker compose up -d --build
⚡
Opsi 2: Linux Baremetal / VM (Node.js + PM2)

Untuk deployment langsung pada server Ubuntu/Debian/RHEL.

# 1. Pastikan Node.js 22 terpasang (node -v)
# 2. Pasang PM2 Process Manager
npm install -g pm2

# 3. Start daemon produksi dengan timezone WIB
pm2 start apps-script/server/start.js \
--name "kpi-xxi" \
--node-args="--disable-warning=ExperimentalWarning"

pm2 startup && pm2 save
Reverse Proxy Nginx & SSL Let's Encrypt (Port 80/443 Publik)

Template konfigurasi nginx-production.conf telah dibuat. Cukup salin ke /etc/nginx/sites-available/ dan jalankan: certbot --nginx -d kpi.cinema21.co.id.
